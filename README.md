# Golwark Games Releases

Repositorio público de distribución de los juegos del universo Golwark. Sirve el catálogo que consulta Golwark Launcher. Los paquetes compilados, cuando existan, se publican como assets de GitHub Releases.

El código fuente de los juegos y del launcher no está en este repositorio.

## Catálogo

[`catalog.json`](catalog.json) se publica con GitHub Pages:

https://radega1993.github.io/golwark-games-releases/catalog.json

En Golwark Launcher, abre **Configuración → URL DEL CATÁLOGO**, pega esa dirección y guarda.

## Descargas

Los ZIP de cada versión van en GitHub Releases, no en GitHub Pages. El catálogo solo anuncia una instalación automática cuando la plataforma tiene `url` HTTPS y `sha256`. Mientras esos campos estén vacíos, el launcher no ofrece una descarga automática.
